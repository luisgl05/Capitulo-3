EJERCICIO 3.2

INSTRUCCIÓN:Indique si cada uno de los siguientes enunciados es verdadero o falso.

Respuestas:

  1. Cualquier tipo input particular de formulario de HTML5 debe desplegarse de manera idéntica en todos los navegadores compatibles con HTML5.
    2. Falso. según el despliegue de los diferentes tipo de inputs puede variar de un navegador a otro.
  2. Cuando se coloca el enfonque en el campo de texto (es decir, si el cursor está en el campo de texto), se envía el texto del atributo placeholder al servidor.
    3. Falso. Cuando se coloca el enfoque en el campo de texto, el texto placeholder desaparece. No se "envía" cuando el usuario hace clic en el botón Enviar
  3. No es necesario incluir autofocus en sus formularios.
    4. Verdadero.
  4. Los nuevos tipos input de HTML5 tienen validación automática del lado del cliente, con lo cual se elimina la necesidad de agregar secuencias de comandos (script) complicadas a sus formularios para validar la entrada del usuario del usuario y reduce la cantidad de datos inválidos que se envían.
    5. Verdadero.
  5. El tipo input range se valida autómaticamente de manera intrínseca cuando el navegador lo despliega como un control deslizante, ya que el usuario no puede mover el control fuera de los límites del valor mínimo máximo.
    6. Verdadero.
  6. HTML5 cuenta con validación automática para el tipo tel.
    7. Falso. La longitud y el formato de los números telefónicos varía de manera considerable según la ubicación, esto indica que en el input tel de HTML5 no cuenta con validación automática, se debe establecer mediante un patron.
  7. Si el usuario introudce un URL con un formato inapropiado en un tipo input url, no se validará. HTML no valida si el URL introducido existe en realidad.
    8. Verdadero.
  8. El elemento nav muestra un menú desplegable de hipervínculos.
    9. Falso. Nav agrupa vínculos de navegación dentro de HTML5.
  9. El elemento header puede usarse sólo una vez en una página.
    10. Falso. El elemento header puede usarse varias veces en una página y a menudo incluye encabezados de HTML.
  10. Los elementos nav pueden anidarse en un elemento aside.
    11. Verdadero.
  11. Podemos usar el elemento brk para evitar dividir palabras en lugares incorrecto.
    12. Falso. Puede usar el elemento wbr para evitar dividir las palabras en lugares incorrectos.
